I

TypeSec — Authority You Cannot Fake

In this world authority is not a password you could copy or a flag you could flip. It is a typed object — mintable only by a policy, narrowable only downward, and impossible to forge because there is no way to make one by hand.

II

LakeCat — Transactions You Can Prove

Below the memory sits the catalog: the single pointer to the current truth of a data lake. Here the question is not "who may act?" but "when something is committed, can a stranger prove what happened, months later, without trusting the server that says so?"

✦

One Boundary, Composed

The mint and the ledger were never two guards. Marciana's memory is TypeSec's crate; LakeCat's scan proof flows upward into Marciana's commits. Prove the boundary in one place and you strengthen a foundation the others stand on.
